# 先问再投（Ask Before Invest）

看到一条热点新闻时，我们很容易直接问：

> “这件事利好什么股票？”

但从热点到投资机会，中间还缺少一条完整的因果链。

**先问再投**是一个 Codex Skill。它不会急着罗列概念股，而是用“道—法—术—器—行”把宽泛的问题重构为可验证的投资问题，并把验证结果翻译成下一步可以采取的行动方向。

## 核心框架：道—法—术—器—行

| 层次 | 在投资研究中解决什么问题 |
|---|---|
| 道 | 决定什么值得看：事件是否可能改变未来现金流、风险或市场预期 |
| 法 | 建立从事件到投资结果的四层因果链 |
| 术 | 把因果链拆成可回答、可证伪的具体问题 |
| 器 | 为问题匹配一手资料、数据、指标和后续研究工具 |
| 行 | 把证据翻译成观察、等待、试探参与、确认加码或证伪退出的条件 |

工具不是起点。先用“道”确定方向，再用“法”建立框架、用“术”提出问题、用“器”寻找证据，最后用“行”明确什么情况采取什么动作。

## 它解决什么问题

例如，输入：

```text
GPT-6 发布，会不会开启新一轮 AI 硬件行情？
```

它会沿着四个必要条件拆解：

1. **真实需求**：事件是否创造了有经济意义的新需求？
2. **净增量**：扣除效率提升、替代和降价后，总需求是否仍然增长？
3. **利润归属**：增量会流向哪个产业瓶颈，最终由谁获得利润？
4. **市场定价**：这些变化是否已经被市场充分计入，何时才适合参与？

最终输出的不是一个仓促的股票名单，而是：

- 原问题为什么不足以直接指导投资；
- 重新定义后的核心问题；
- 四个必要条件；
- 有优先级、可验证的研究问题；
- 每个关键判断的假设、证伪信号和证据路径；
- 一张条件式“验证—动作地图”，说明何时观察、参与、提高参与度或退出；
- 最终必须搞清楚的三至五个决定性问题。

## 适用场景

- 新模型、新产品或新技术发布；
- 产业政策和监管变化；
- 公司财报、订单及资本开支变化；
- “某事件利好哪些股票”；
- “某板块会不会开启新一轮行情”。

## 不适合做什么

这个 Skill 可以给出条件式行动方向，但不会在缺少实时数据、风险承受能力和组合约束时，无条件推荐个股、规定精确仓位或代替用户做买卖决定。

## 安装

将本仓库下载或克隆到 Codex Skills 目录：

```bash
git clone https://github.com/holly-game/ask-before-invest.git ~/.codex/skills/ask-before-invest
```

## 使用

在 Codex 中输入：

```text
$ask-before-invest GPT-6 发布，会不会开启新一轮 AI 硬件行情？
```

也可以直接提出类似问题；当任务符合适用范围时，Codex 可以自动选择这个 Skill。
