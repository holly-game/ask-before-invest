# 先问再投（Ask Before Invest）

看到一条热点新闻时，我们很容易直接问：

> “这件事利好什么股票？”

但从热点到投资机会，中间还缺少一条完整的因果链。

**先问再投**是一个 Codex Skill。它不会急着罗列概念股，而是用“看本质—列条件—提问题—找证据—定行动”五个简单步骤，把宽泛的问题重构为可验证的投资问题，并把验证结果翻译成下一步可以采取的行动方向。

## 核心框架：五个简单步骤

| 步骤 | 要解决什么问题 |
|---|---|
| 看本质 | 这件事为什么可能影响未来现金流、风险或市场预期 |
| 列条件 | 投资逻辑成立必须满足哪些条件 |
| 提问题 | 为了判断条件是否成立，具体要搞清楚什么 |
| 找证据 | 用哪些一手资料、数据和指标验证 |
| 定行动 | 出现什么验证后，应该观察、等待、参与或退出 |

工具不是起点。先看清本质，再列出成立条件、提出问题、寻找证据，最后才决定采取什么动作。

## 它解决什么问题

例如，输入：

```text
GPT-6 发布，会不会开启新一轮 AI 硬件行情？
```

这个案例不会直接跳到“买哪只股票”，而会完整走过五层：

### 第一步：看本质

GPT-6 只有在改变 AI 的使用量、总算力需求、产业链利润或市场预期时，才可能开启新的硬件行情。单纯的模型跑分、发布会热度和概念股异动不是充分证据。

### 第二步：列条件

1. **真实需求**：GPT-6 是否创造了新的高价值任务，并提高用户数量、调用频率或付费意愿？
2. **净增量**：模型效率可能降低单位算力成本；任务增长是否足以抵消效率提升，使总算力需求仍然增加？
3. **利润归属**：增量会落到 GPU、ASIC、HBM、光模块、电力还是云服务？哪个环节真正存在瓶颈和议价权？
4. **市场定价**：相关公司的盈利预期是否上修？当前股价是否已经透支最乐观的情景？

### 第三步：提问题

- GPT-6 发布后，API 调用量、企业采用率和单次任务计算量是否持续增长？
- 云厂商是否因此上调资本开支，而不是只调整原有预算结构？
- 硬件公司的订单、交付周期、毛利率和盈利指引是否同步改善？
- 如果调用增长但单位计算成本下降得更快，硬件需求故事是否应当被否定？

### 第四步：找证据

- 模型官方报告、产品定价、API 使用和客户案例；
- 云厂商资本开支、GPU 利用率和数据中心建设计划；
- 芯片、存储、光通信及电力设备公司的财报、订单和电话会；
- 盈利预测变化、估值、股价反应和市场拥挤度。

### 第五步：定行动

| 出现的验证 | 行动方向 |
|---|---|
| 只有发布热度，需求与资本开支尚未验证 | 保持观察，不从概念股名单直接选股票 |
| 使用量和总算力需求出现早期增长，但利润归属不清 | 纳入观察池；若要参与，优先采用分散、可撤回的方式 |
| 资本开支、订单和盈利预期同步上修 | 聚焦能把需求转化为利润的直接瓶颈，考虑试探性参与 |
| 四个条件成立，估值仍有空间且催化清楚 | 可以考虑提高参与度，同时预先写明退出条件 |
| 效率提升抵消需求、订单未兑现或估值已经透支 | 继续等待、降低追价意愿；核心逻辑被推翻时退出研究 |

因此，这个案例最终要回答的不是“GPT-6 利好哪些股票”，而是：

> GPT-6 能否让总算力需求在效率提升后仍然净增长；增量由哪个瓶颈转化为利润；市场是否尚未充分定价；出现哪些证据后，才可以从观察升级为参与？

最终输出的不是一个仓促的股票名单，而是：

- 原问题为什么不足以直接指导投资；
- 重新定义后的核心问题；
- 四个必要条件；
- 有优先级、可验证的研究问题；
- 每个关键判断的假设、证伪信号和证据路径；
- 一张条件式“验证—动作地图”，说明何时观察、参与、提高参与度或退出；
- 最终必须搞清楚的三至五个决定性问题。

## 适用场景

- 新模型、新产品或新技术发布；
- 产业政策和监管变化；
- 公司财报、订单及资本开支变化；
- “某事件利好哪些股票”；
- “某板块会不会开启新一轮行情”。

## 不适合做什么

这个 Skill 可以给出条件式行动方向，但不会在缺少实时数据、风险承受能力和组合约束时，无条件推荐个股、规定精确仓位或代替用户做买卖决定。

## 安装

将本仓库下载或克隆到 Codex Skills 目录：

```bash
git clone https://github.com/holly-game/ask-before-invest.git ~/.codex/skills/ask-before-invest
```

## 使用

在 Codex 中输入：

```text
$ask-before-invest GPT-6 发布，会不会开启新一轮 AI 硬件行情？
```

也可以直接提出类似问题；当任务符合适用范围时，Codex 可以自动选择这个 Skill。
